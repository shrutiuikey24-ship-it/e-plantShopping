
# Paradise Nursery Shopping Application

Paradise Nursery is a React-based online plant shopping application
that helps users explore indoor plants and manage their shopping cart.

## Features

- Landing page with a Get Started button
- Navigation between Home, Plants, About Us, and Cart
- Plant listings organized into two categories
- Product images, descriptions, and prices
- Add plants to the cart
- Increase and decrease item quantities
- Delete products from the cart
- Automatic subtotal and total calculations
- Continue Shopping and Checkout buttons
- Redux Toolkit state management
- Responsive layout for desktop and mobile

## Technologies Used

- React
- Vite
- Redux Toolkit
- React Redux
- CSS
- JavaScript
- GitHub

## Run Locally

Install Node.js, then run:

```bash
npm install
npm run dev
```

## Project Structure

- `index.html` - HTML entry point
- `main.jsx` - React entry point and Redux Provider
- `App.jsx` - Main application and navigation
- `App.css` - Styling and landing page background
- `AboutUs.jsx` - Company information
- `ProductList.jsx` - Plant listing
- `CartSlice.jsx` - Redux cart reducers
- `CartItem.jsx` - Shopping cart interface
- `store.js` - Redux store configuration

Created as a final project for the Paradise Nursery Shopping
